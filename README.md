# 零售销售数据可视化分析项目

## 项目简介

基于模拟零售销售数据（2026 上半年 × 5 大地区 × 5 大品类），完成完整的可视化分析报告，覆盖核心指标、月度趋势、品类占比、分布、关联、热力矩阵 6 大分析模块。

## 技术栈

- Python 3.x
- NumPy / Pandas
- Matplotlib / Seaborn / Plotly（px）

## 功能特性

- ✅ **数据生成**：模拟 4500+ 条销售明细（日期、地区、品类、销售额、订单量、利润）
- ✅ **核心指标**：总销售额、总订单量、平均客单价、月度环比增长率
- ✅ **月度趋势分析**：resample("MS") 按月重采样，折线图展示趋势
- ✅ **品类分析**：环形图看占比、柱状图看排名
- ✅ **分布分析**：直方图 + 箱线图看日销售额分布及地区差异
- ✅ **关联分析**：散点图 + OLS 回归线，探索销售额与利润的关系
- ✅ **热力矩阵**：pivot_table 透视 + heatmap，一图看清「地区 × 品类」销售格局

## 分析模块结构

```
核心指标（KPI 概览）
   ↓
趋势（月度销售趋势）
   ↓
构成（品类占比 / 排名）
   ↓
分布（直方图 / 箱线图）
   ↓
关联（销售额 vs 利润回归）
   ↓
矩阵（地区 × 品类热力图）
```

> 代码说明：图表代码默认注释，放开对应注释即可运行；Plotly 输出交互式图表，Seaborn/Matplotlib 输出静态图。

## 运行方式

```
python retail_sale_data_visualization.py
```
